# IMAS - Multi-Agent System for Emergency Response Simulation

This repository contains the coursework for the IMAS course, focusing on the design and implementation of a Multi-Agent System (MAS) for managing emergency responses in an urban environment.

## Project Structure

The project is divided into three main tasks:

### [Task 1](./task1)

**Initial Design & Analysis**

- Environment analysis (Accessibility, Determinism, Episodicity, Dynamism, Continuity).
- Selection and definition of crews and agent roles.
- Classification of agents within the system.
- Initial sequence diagrams and reports.

### [Task 2](./task2)

**Refinement & Process Definition**

- Rework of agent types.
- Process definitions and flow diagrams.
- Pydantic models for agent outputs (Emergency, Firefighter, Medical, Police crews).

### [Task 3](./task3)

**Implementation: City Emergency Response Flow**

- Implementation of the multi-agent system using the **CrewAI** framework.
- Integration with OpenStreetMap data via OSMnx.
- Features include emergency assessment, response coordination, ethical decision-making, and route optimization.
